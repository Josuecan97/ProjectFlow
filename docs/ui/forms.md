# Formularios

> Estado: Activo
> Última actualización: 2026-07-24

## Principios

- Validación en servidor y errores junto al campo.
- Etiquetas visibles y ayudas comprensibles.
- Valores anteriores se conservan cuando exista error.
- Acciones destructivas requieren confirmación.
- Formularios de Persona cambian campos obligatorios según física o moral.
- Advertencias de duplicado no bloqueantes se muestran antes de guardar cuando sea
  posible; RFC duplicado sí bloquea.
- Ningún formulario acepta `organization_id` como autoridad del cliente.
