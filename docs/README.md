## Uso recomendado

Antes de implementar cualquier funcionalidad:

1. Leer [AI Context](AI_CONTEXT.MD).
2. Leer los documentos relacionados con el módulo o área afectada.
3. Revisar [Decisions](DECISIONS.MD) y los ADR relacionados.
4. Confirmar que el cambio esté alineado con [Roadmap](ROADMAP.MD).
5. Mantener la documentación sincronizada con el código.
